# 検証と公開前チェック

## 自動テスト

`npm test` は外部APIをモックし、認証、受付期間、入力検証、AI対話の署名、集計、複製、CSV・JSON、Sheets保存・表出力、PostgreSQL接続設定・トランザクション処理を確認します。最後の質問にクロージング指示を追加し、要約には質問指示を混ぜないことも検証します。
`npm run build` はブラウザ用のアイコン・PDF処理ライブラリを準備します。

### ブラウザ回帰テスト

Playwrightと対応するChromiumを別途用意し、`.env`を読み込まずに実行します。

```sh
node scripts/check-required-interview-ui.mjs
node scripts/check-survey-wizard-ui.mjs
```

Playwrightが別の場所にある場合は`PLAYWRIGHT_MODULE`に`index.mjs`の絶対パスを、ブラウザを指定する場合は`CHROME_PATH`に実行ファイルのパスを設定してください。

- 必須設定：設問が必須の場合だけAI必須を選択でき、任意に戻すと解除されること。保存・再表示と、未完了の必須AIでは先に進めないこと。
- 画面遷移：1問ずつの表示と進捗、通常回答の必須チェック、任意AIのスキップ、戻る・確認画面からの修正で入力・会話が残ること。
- 会話：リセットの確認、最後の質問から回答・要約への遷移、全体インタビュー、最終送信まで回答を保存しないこと。
- 表示：スマートフォン幅で横方向にはみ出さないこと。

いずれも一時的なローカルサーバーとメモリ内保存、モックAIを使い、実DB・Google・外部AIには接続しません。

## 公開前

- [ ] Git登録対象に秘密鍵、環境変数の実値、回答データが含まれていない。
- [ ] 本番用の管理者パスワード・署名用シークレットを設定した。
- [ ] ProductionとPreviewの保存先（個別設定を含む）を分離した。
- [ ] Sheets利用時は対象ファイルをサービスアカウントに編集者として共有した。PostgreSQL利用時は専用テーブルの初期化と接続確認を済ませた。
- [ ] AI費用と受付期間を確認した。

## Vercelデプロイ後

- [ ] 管理者ログイン・ログアウト、未認証アクセスの拒否。
- [ ] 回答保存、AI対話、CSV・JSON出力。
- [ ] 選択した保存先への保存。Sheetsでは原本保存と表形式タブの更新、PostgreSQLでは保存・重複防止。
- [ ] 1問ずつの遷移、必須チェック、戻る・修正、確認後送信。
- [ ] 実際に利用するAIモデルが最後の質問で考えの整理を促し、その回答後は質問ではなく要約を返す。
- [ ] 受付前・受付終了後の回答とAI利用の拒否。
- [ ] 本番URL、Cookie、環境変数、APIルーティング。
- [ ] 保存失敗時の表示と再送。

過去の公開確認と、新しい変更の確認は区別してください。デプロイの成功だけでは実AIや本番の回答保存を検証したことにはなりません。公開のたびに上記チェックを実施してください。手順と設定はREADMEを参照してください。
