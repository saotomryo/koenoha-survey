# 検証と公開前チェック

## 自動テスト

`npm test` は外部APIをモックし、認証、受付期間、入力検証、AI対話の署名、集計、複製、CSV・JSON、Sheets保存・表出力を確認します。
`npm run build` はブラウザ用アイコンライブラリを生成します。

## 実施済みの確認

- ローカル画面で管理・回答・AI対話・保存の動作確認。
- OpenAIへの接続と質問生成。
- Google Sheetsへの接続と閲覧用タブ作成。
- これらは個別の確認であり、すべてのモデル・クラウド環境の動作保証ではありません。

## 公開前

- [ ] Git登録対象に秘密鍵、環境変数の実値、回答データが含まれていない。
- [ ] 本番用の管理者パスワード・署名用シークレットを設定した。
- [ ] ProductionとPreviewの保存先（個別設定を含む）を分離した。
- [ ] 対象ファイルをサービスアカウントに編集者として共有した。
- [ ] AI費用と受付期間を確認した。

## Vercelデプロイ後

- [ ] 管理者ログイン・ログアウト、未認証アクセスの拒否。
- [ ] 回答保存、AI対話、CSV・JSON出力。
- [ ] Sheetsの原本保存と表形式タブの更新。
- [ ] 受付前・受付終了後の回答とAI利用の拒否。
- [ ] 本番URL、Cookie、環境変数、APIルーティング。
- [ ] 保存失敗時の表示と再送。

Vercelでの本番動作確認は未実施です。手順と設定はREADMEを参照してください。
